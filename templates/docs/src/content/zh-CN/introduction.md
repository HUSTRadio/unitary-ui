# 欢迎使用 Orbit

在一个清晰的工作空间中规划项目、管理资源，了解每一步的进展。

## 从这里开始

阅读[快速开始](getting-started.md)，创建你的第一个项目。然后参考[配置指南](configuration.md)调整工作空间。

## 核心概念

| 概念     | 用途                       |
| -------- | -------------------------- |
| 项目     | 一组具有共同交付目标的工作 |
| 资源     | 与项目关联的文件和链接     |
| 工作空间 | 团队共同工作的地方         |

### 项目与资源

为项目设置清晰的目标与负责人，将需要的资料整理为资源。

## 文档导航

使用左侧导航浏览指南，或打开搜索寻找正文中的关键词。页面右侧目录可直接定位到章节。

> 此站点使用示例内容。替换 Markdown 文件即可维护你自己的项目文档。

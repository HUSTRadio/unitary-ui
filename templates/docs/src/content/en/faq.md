# FAQ

A few things to know before you begin.

## Does the example connect to a server?

No. Templates use local demo data, and business actions affect only the current page session.

## How do I add a document?

Add matching Markdown files to both language content directories, then register the title, identifier, and group in the content registry. Navigation and search use that registry.

## How do I share a section?

Click a section in the page outline and copy the browser address. Section identifiers are generated from headings.

## How do I change a code example?

Edit the fenced code block in Markdown. The standard CodeBlock component provides language highlighting and a copy button.

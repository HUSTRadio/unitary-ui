# Configuration

Make the workspace fit your team.

## Workspace settings

Choose a clear team name and decide whether to enable the weekly digest.

```json
{
  "name": "Product team",
  "weeklyDigest": true
}
```

## Appearance and language

The interface supports light, dark, and system themes, with Chinese and English language options.

### Accessibility

Use the keyboard to reach navigation and actions. Tables and code blocks scroll inside their own containers.

## Connecting data

The example uses local data. When connecting a real service, replace the business data source and provide loading, error, and empty states.

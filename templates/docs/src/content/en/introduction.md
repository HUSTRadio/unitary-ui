# Welcome to Orbit

Plan projects, manage resources, and follow every step in one clear workspace.

## Start here

Read [Getting started](getting-started.md) to create your first project. Then use [Configuration](configuration.md) to adjust your workspace.

## Core concepts

| Concept   | Purpose                                   |
| --------- | ----------------------------------------- |
| Project   | Work with a shared delivery goal          |
| Resource  | Files and links associated with a project |
| Workspace | A place for your team to work together    |

### Projects and resources

Give each project a clear goal and an owner, and organize its supporting materials as resources.

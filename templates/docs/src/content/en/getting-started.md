# Getting started

Set up your first workspace in three steps.

## Create a workspace

Choose a name your team recognizes, then describe the project goal.

```json
{
  "workspace": "Product team",
  "project": "First delivery"
}
```

## Organize a project

1. Define the delivery goal.
2. Assign an owner.
3. Gather related files and links.

### Set project status

Use `active` for projects in progress and `paused` for projects on hold.

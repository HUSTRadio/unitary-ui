# Changelog

[← 简体中文版本：CHANGELOG.md](./CHANGELOG.md)

All notable changes to this project are documented in this file. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versioning follows Semantic Versioning.

## [Unreleased]

### Fixed

- **Published documentation artifact recovery**: exempts only the receipt- and integrity-verified exact library version from the registry consumer's release-age wait; external dependencies retain the existing policy. Adds `--release-root` so current clean tooling can recover docs from a clean checkout of the original release commit, retaining source, frozen-lock, complete browser and bilingual corpus checks. These post-publication tooling fixes are not included in the beta.1 tarball.

## [0.1.0-beta.1] - 2026-10-12

### Added

- **Public documentation consumption**: Exports `scrollIntoViewWithMotion`, `ScrollAnimation`, and `NAV_CONTENT_INSET`; adds `@hustradio/unitary-ui/tailwind-reference.css`, generated from canonical CSS so consumers can compile their own Tailwind utilities.

### Changed

- **Documentation structure**: Keeps docs in the repository as a private workspace using public package imports. Local development resolves source; release candidates and published static artifacts consume independently installed packages. Separates library configuration, stylesheet scanning, and declaration entries, with frozen locks, full browser coverage, bilingual corpus comparison, and publication receipt validation. The release workflow retains deployable documentation artifacts.

### Fixed

- **Portable documentation CLI**: launches corpus previews and formatting through Node and the project's pinned Vite+ CLI, removing the dependency on a globally installed `vp.exe`. The formatter check retains only Node on PATH, still requires the complete corpus to have no formatting drift, and reports launch errors explicitly.

- **Browser CI runner consistency**: moves the four job definitions running complete browser matrices to Windows 2025 based on paired tests of pre- and post-migration source. Retains every source, independent candidate-package and published-package docs case, both themes, all viewports, existing job limits, and the 20ms frame-time P95 gate. Old source also failed the Ubuntu comparison; both commits passed twice on Windows. The [diagnostic record](./docs/audits/browser-runner-2026-10-12.md) preserves the environment and limits of the conclusion.

- **Publication scanning recovery**: waits read-only for up to 20 minutes after an accepted npm upload, within a 30-minute publishing job; documents first-package tags and the trusted publisher 48-hour validation deadline. These follow-up changes are not included in the published beta.0 tarball.

## [0.1.0-beta.0] - 2026-10-11

### Changed

- **npm release preparation**: validates the actual pnpm tarball in an independent TypeScript and browser consumer, cleans stale library output, and prepares manual `0.1.0-beta.0` publishing to `beta` without a GitHub Release, retaining future stable Release publishing with first-package token bootstrap followed by OIDC. Includes bilingual publishing instructions and the Material Symbols keycap font license notice. Published `0.1.0-beta.0` under `beta` with provenance after all required checks; the stable GitHub Release remains a draft.

- **Nonlinear motion curves**: aligns the component library, website, styleguide and Hitu illustrations around quick responses, soft finishes or smooth starts and finishes. The three Bezier curves are project-selected values, not official Apple parameters, and add no spring engine. Retains the 150 / 250 / 350 / 500ms duration tiers, with CSS as the only parameter source and JS defaults derived by the token generator; entering and existing independent exit phases consume semantic curves. Continuous loading rotations remain constant-rate, native gestures remain direct, and data geometry interpolation is unchanged.
- **Motion and Hitu easing contract**: all four `useMotionTransition` tiers read `--ease-snap`, retaining valid scoped nonlinear overrides; linear or identity-Bezier configurations complete instantly. Omitting `HituFrame.cubic` changes Hitu's former linear interpolation to `[0.42, 0, 0.58, 1]`, while explicit nonlinear curves remain supported. Shared time-progress solving preserves endpoints and sparse-transform inheritance.
- **Carousel and programmatic scrolling migration**: narrows `CarouselVariant` to `"slide" | "fade" | "fade-scale"`, removing `fade-linear` in favor of `fade`; every effect uses a quick-finish curve. Scroller direction buttons, the four chart legends and website anchors use the state duration and a smooth start and finish. New requests on a container continue from the current position, and user input cancels active animations. Tooltip movement in AreaChart, BarChart, LineChart and ComboChart uses feedback timing and a quick-finish curve; reduced motion positions immediately, and legend state follows actual scrolling.
- **Bilingual motion specification and examples**: adds the [nonlinear motion specification](./docs/design/apple-motion-curves.en.md), covering curve provenance, governance exceptions and migration steps; synchronizes the Motion / Hitu, Carousel, Scroller and chart APIs, guides and live examples. The historical Hitu integration audit is preserved.

# Prefetch verification / 预载验证

规划见 [Prefetch design](../design/prefetch.md)。公共资源、触发器、文档导航及双语指南按该契约实现。/ The public resource, triggers, docs navigation and bilingual guides implement the [design](../design/prefetch.md).

## Behavior / 行为

- `createPrefetch` 不在创建时加载；并发、重入、预载与显式加载共享 Promise，成功后复用缓存。后台失败记录状态并可重试。/ Creation starts no work; concurrent, reentrant, background and explicit loading share a promise and successful cache. Background errors remain observable and retryable.
- 失效中止支持信号的旧请求，旧成功或拒绝不能覆盖新缓存。组件卸载仅取消调度，共享请求继续供其他消费者使用。/ Invalidation aborts signal-aware work; stale success or rejection cannot overwrite the new cache. Unmounting cancels scheduling while preserving work for other consumers.
- 三种触发覆盖鼠标、键盘、触摸、局部滚动视口及浏览器空闲；自动触发尊重省流量设置。SSR 不自动加载。/ Triggers cover mouse, keyboard, touch, local viewports and browser idle time; automatic work respects Data Saver. SSR starts no automatic loading.
- 文档导航和实际渲染使用相同资源；首页不下载演示，悬停 Carousel 链接只准备目标页面及 Carousel 演示，点击后不重复请求。/ Docs intent and rendering share resources; home requests no demos, Carousel hover prepares only its page/examples, and clicking adds no duplicate request.

# Documentation policy

Except for instructions addressed to LLMs, write explanatory documentation and valuable maintenance comments in Simplified Chinese first, with an equivalent English alternative.

Verify canonical implementation exports, TypeScript props, live demos, API registries, human documentation, and generated reference pages. Never invent an API, state, event, accessibility behavior, or demo identifier.

Keep locale-neutral route IDs, example IDs, API names, code, commands, and links identical across locales. Deterministic generation and validation results are authoritative over prose or changelog claims.
